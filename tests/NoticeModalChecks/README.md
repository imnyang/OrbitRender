# 충돌 복구 모달 검증

`RunUI.ps1`은 실제 NoticeModal/UguiFactory 소스를 별도의 Unity 프로젝트로 복사하고 플레이 모드에서 실행한다. 게임 실행이나 종료, 실제 모드 비활성화는 하지 않는다. 외부 동작만 스텁으로 대체한다. 결과와 한국어·영어·스페인어 스크린샷은 `packages/NoticeModalChecks`에 생성된다.

`powershell.exe -NoProfile -File tests/NoticeModalChecks/VerifyRecovery.ps1`은 빌드한 OrbitRender와 실제 UMM DLL을 임시 폴더에서 로드한다. 게임의 Params.xml은 수정하지 않는다. 비활성화 저장, 저장 실패 시 롤백, Steam 재시작 스크립트의 대기 처리 및 URI 전달을 검사한다. Steam 실행 호출은 테스트 함수로 가로채므로 게임을 실행하지 않는다. `-GameDir`로 게임 경로를 지정할 수 있다.

2026-11-14 검증 결과:

- Release 빌드 통과.
- 실제 UMM의 비활성화 설정 저장 및 실패 시 메모리 상태 롤백 통과.
- Unity 6000.3.25f1 플레이 모드: 3개 언어에서 진단 복사, 비활성화 성공/실패, 재시작 확인 및 성공/실패 콜백, 후보 없음, 지원하지 않는 플랫폼, 기존 복구 재시도, 닫기 검증 통과.
- 640×480에서 3개 언어 스크린샷을 직접 확인했다. 본문과 후보 목록은 스크롤되고 재시작 경고와 하단 버튼은 고정된다.
- 실제 게임 프로세스 종료·재실행은 실행하지 않았다. 해당 동작은 Windows에서만 제공하며 다른 플랫폼은 런처에서 직접 재시작하도록 표시한다. 기존 프로세스 종료 후 Steam URI `steam://rungameid/977950`를 호출하며 게임 실행 파일을 직접 실행하지 않는다.

## UI Delivery Gate

- Hard Gate PASS: 새 이미지·통계·내비게이션 없이 기존 게임 오류 모달을 확장했다. 640×480의 다국어 화면에서 가로 넘침·버튼 겹침이 없다. 일반 본문/버튼 텍스트 대비 10.17:1, 포커스 색/버튼 배경 대비 5.91:1을 계산했다.
- Purpose Gate PASS: 기존 UguiFactory 색·글꼴·모서리를 재사용한다. 스크롤 영역은 오류와 후보를 담고, 고정 하단은 데이터 손실 경고와 사용자 동작을 분리한다. 장식이나 애니메이션을 추가하지 않았다.
- Liveliness PASS: 게임 렌더링 실패에서 복구를 선택하는 사용자용 모달, 기존 OrbitRender 시각 언어, ENERGY 1 / RHYTHM 1 / MOTION 1. 오류 제목과 기본 확인 버튼이 계층을 만들며 모드명·버전·ID가 실제 식별 정보로 제시된다.
- Craftsmanship PASS: 플레이 모드에서 복사·모드 비활성화·재시작 확인·실패 표시·닫기·기존 재시도 콜백을 실행했다. 원인 확정과 후보를 혼동하지 않도록 후보라는 설명을 제공한다. 키보드 선택에는 테두리 표시를, 스크롤 목록에는 선택 항목 표시 처리를 추가했다.
